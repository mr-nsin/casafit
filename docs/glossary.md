# CasaFit · Glossary

The vocabulary an agent is likely to meet. Only new or product-specific terms are listed.

| Term | Meaning |
|---|---|
| **15-minute shape** | Every session is 2 min warm-up + 11 min work + 2 min cool-down. The warm-up matches today's muscles. The cool-down is rebuilt when the user edits the session. |
| **Free form check** | A camera-based pose check on squat, push-up, plank or lunge. A free account has 2 for the lifetime of the account. |
| **Pro** | Paid tier. Unlimited form checks. Everything else stays free. |
| **Lane** | A git-worktree branch owned by one agent or person. See `CLAUDE.md`. The names are `docs`, `onboarding`, `session`, `features`. |
| **Integrator** | The role (person or agent) that merges lanes, rebuilds `project/canvas.json` and publishes the design canvas. |
| **Plan engine** | The on-device rules that build a week-one plan from onboarding answers. No AI at build time. |
| **Content catalogue** | The exercise library: videos, demos, muscle tags and the substitution ladder. Bundled or Wi-Fi-only download. |
| **Substitution ladder** | For every exercise: an easier, a harder and a no-equipment version. Covers injuries, missing kit, bad days and progression as one mechanism. |
| **Style** | Normal, yoga or dance. A plan can mix two or three. |
| **Mix** | How many days per week each style gets. The customise screen edits this. |
| **Quiet mode** | A session setting. Swaps jumping and plyometric moves for low-impact versions, uses vibration instead of beeps. For flats with neighbours. |
| **DPDP** | India's Digital Personal Data Protection Act, 2023. Rules apply in full about 13 May 2027. |
| **Health Connect / HealthKit** | Platform aggregators for health data. CasaFit reads step counts from them, never from GPS. |
| **DLT** | Distributed Ledger Technology — the telecom portal where sender IDs and SMS templates must be registered before CasaFit can send OTPs in India. |
| **Idempotency key** | Client-generated string sent with every entitlement call so a retry does not double-spend a credit. |
| **Katori / chamach / roti count** | Indian portion units in the food log. One katori is a small steel bowl. |
| **Comeback path** | The screen a user sees when they return after 7+ days away. Not a broken-streak screen. |
| **Reduced motion** | A platform setting the app respects. Loops stop; the first frame of a demo is shown. |
| **Reverse walk** | Walking backwards. Opt-in, timed, capped at 15 minutes a day. Hidden for users with a health flag. |
| **Memory (as used in `MEMORY.md`)** | This repo's `docs/` folder, not the kind the mobile client holds in RAM. See `docs-agent.md`. |
